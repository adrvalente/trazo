# Quadro V0.3.5.7 — Zoom Radial

Base: V0.3.5.6. Os controlos de zoom existentes foram reorganizados num menu circular flutuante. O botão abre o menu, que se fecha após 3 segundos sem interação, ao tocar fora ou premir Esc. Mantêm-se zoom +, zoom −, percentagem e repor vista, com os mesmos IDs e eventos do motor original. A posição do zoom evita o canto ocupado pelo menu principal quando este está visível no canto inferior direito. O botão de zoom respeita a preferência Mostrar controlos de zoom. Não foi alterado o motor app.js. Compatível com GitHub Pages.
